# 💳 Credit Card Fraud Detection System

A Machine Learning project designed to detect fraudulent credit card transactions using classification algorithms and class-imbalance handling techniques.

---

## 🚀 Project Overview

Credit card fraud detection is a classic imbalanced classification problem where fraudulent transactions represent a tiny fraction of total activity. This project preprocesses transaction features, handles class imbalance, and trains a machine learning classifier to accurately flag suspicious transactions while minimizing false positives.

---

## ✨ Features

* 📊 **Fraud Detection Classification** — Identifies legitimate vs. fraudulent transactions
* ⚖️ **Class Imbalance Handling** — Addresses skewed fraud/non-fraud ratios
* 🧹 **Automated Feature Scaling & Preprocessing** — Standardizes transaction amounts and time features
* 📈 **Comprehensive Evaluation** — Evaluates performance using Precision, Recall, F1-Score, and ROC-AUC
* 📁 **Clean Project Structure** — Modular code and reproducible workflow
